# Руководство владельца / администратора

Как управлять ботом «Маскированные звонки» в повседневной работе.
(Техническая установка — в [DEPLOYMENT.md](DEPLOYMENT.md).)

---

## Роли в системе

- **Администратор** — это вы. Заводите группы, операторов и менеджеров.
  Назначается через `ADMIN_TG_IDS` в настройках (`.env`).
- **Оператор** — сотрудник отдела продаж. Создаёт заявки, одобряет звонки.
- **Менеджер** — выездной сотрудник. Получает заявки, звонит клиентам.

---

## Что такое «группы»

Работа построена вокруг **рабочих групп** (Группа-1, Группа-2, Казань, Группа-5 и т.д.).
В каждой группе в любой момент работает **ровно один** менеджер. Когда менеджер
меняется — вы назначаете нового, а прежний автоматически открепляется от группы
(новые заявки ему приходить перестают).

При первом запуске бот сам создаёт предзаполненный список групп. Посмотреть —
`/groups`. Добавить новую — `/add_group`.

---

## Первый запуск

1. После установки откройте бота в Telegram и нажмите `/start`.
   Так как ваш ID указан в `ADMIN_TG_IDS`, вы автоматически станете администратором.
2. Проверьте: `/me` — должно показать роль «администратор».
3. Посмотрите группы: `/groups`.

---

## Порядок настройки

### Шаг 1. Проверьте группы

```
/groups
```
Если каких-то групп не хватает — создайте:
```
/add_group Группа-4 Москва
```
(первое слово — название, остальное — город), либо запустите `/add_group` без
аргументов и вводите название и город пошагово.

### Шаг 2. Добавьте операторов

**Важно:** сначала сотрудник должен сам написать боту `/start` — бот покажет ему
его Telegram ID. Сотрудник присылает вам этот ID (число).

```
/add_operator 123456789
```

### Шаг 3. Добавьте менеджеров

```
/add_manager
```
Дальше бот предложит:
- **переслать его сообщение** (самый простой способ — бот сам узнает ID), либо
- ввести `@username` / числовой Telegram ID.

После этого выберите **группу**. Если группа уже занята другим менеджером — бот
спросит подтверждение замены. При подтверждении прежний менеджер открепляется
(остаётся в системе, но без группы), а новому бот предложит **поделиться номером
телефона**. Пока номер не сохранён — звонить менеджер не сможет.

---

## Почему добавление по ID / пересылке, а не по @username

Telegram не позволяет боту узнать ID пользователя по `@username` и не разрешает
боту писать человеку первым, пока тот сам не начал диалог. Поэтому:

1. Сотрудник пишет боту `/start` (или вы пересылаете его сообщение).
2. Бот узнаёт его ID.
3. Вы добавляете его командой.

`@username` сработает только для тех, кто уже писал боту.

## Команды администратора

| Команда | Что делает |
|---|---|
| `/add_group <название> <город>` | создать группу |
| `/groups` | список групп и их текущих менеджеров |
| `/add_operator <tg_id>` | добавить оператора |
| `/add_manager` | добавить менеджера (пересылка/username → выбор группы) |
| `/users` | список всех пользователей с ролями и группами |
| `/remove_user <tg_id>` | деактивировать пользователя (освобождает группу) |
| `/amo_fields` | показать поля amoCRM с их ID (для настройки адреса) |
| `/set_amo_code <code>` | обновить авторизацию amoCRM (если токен истёк) |
| `/me`, `/help` | о себе / справка |

Команды можно вызывать и без аргумента — бот сам спросит данные пошагово.
Прервать любой диалог — `/cancel`.

---

## amoCRM: настройка и заглушка

- **Пока ключи amoCRM не получены**, бот работает в режиме-заглушке: при создании
  заявки `/order` показывает тестового клиента. Это нормально — так можно проверить
  весь процесс до подключения amoCRM.
- **После подключения** (реквизиты в `.env` + код авторизации) бот тянет реальные
  данные сделки. Если авторизация amoCRM слетела (например, прошло много времени) —
  получите новый код в настройках интеграции amoCRM и примените: `/set_amo_code <code>`.
- **Поле адреса**: `/amo_fields` покажет список полей с ID — найдите адрес и
  передайте ID тому, кто настраивает сервер (он впишет `AMO_ADDRESS_FIELD_ID`).
  Телефон бот находит автоматически.

## Контроль и эксплуатация

- **Заявки не теряются**: статусы в БД, журнал звонков — в таблице `call_log`.
- **Если уведомление не пришло** новому сотруднику — значит он ещё не писал боту.
  Попросите его отправить `/start`, затем повторите команду.
- **Деактивация сотрудника**: `/remove_user <tg_id>` — он перестанет получать
  заявки; если был менеджером группы, группа освобождается.
- **Безопасность**: номер телефона клиента нигде в Telegram не показывается.
  Он используется только в момент звонка.

---

## Типичные ситуации

| Ситуация | Что делать |
|---|---|
| Менеджер не получает заявки | `/users`: активен ли он и привязан ли к нужной группе |
| Менеджер не может позвонить | Не поделился номером — пусть нажмёт `/start` и поделится контактом |
| Нужно сменить менеджера группы | `/add_manager` → выбрать ту же группу → подтвердить замену |
| Оператор уволился | `/remove_user <tg_id>` |
| `/order` показывает «Тестовый Клиент» | amoCRM ещё не подключён (режим-заглушка) |
| «amoCRM не настроен» при `/amo_fields` | Заполнить реквизиты amoCRM и авторизоваться |
