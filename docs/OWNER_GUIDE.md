# Руководство владельца / администратора

Как управлять ботом «Маскированные звонки» в повседневной работе.
(Техническая установка — в [DEPLOYMENT.md](DEPLOYMENT.md).)

---

## Роли в системе

- **Администратор** — это вы. Заводите регионы, операторов и менеджеров.
  Назначается через `ADMIN_TG_IDS` в настройках (`.env`).
- **Оператор** — сотрудник отдела продаж. Создаёт заявки, одобряет звонки.
- **Менеджер** — выездной сотрудник. Берёт заявки, звонит клиентам.

---

## Первый запуск

1. После установки откройте бота в Telegram и нажмите `/start`.
   Так как ваш ID указан в `ADMIN_TG_IDS`, вы автоматически станете администратором.
2. Проверьте: `/me` — должно показать роль «администратор».

---

## Порядок настройки (один раз)

### Шаг 1. Создайте регионы

```
/add_region Москва
/add_region Москва
```
Посмотреть список: `/regions`.

### Шаг 2. Добавьте операторов

**Важно:** сначала сотрудник должен сам написать боту `/start` — бот покажет ему
его Telegram ID. Сотрудник присылает вам этот ID (число).

```
/add_operator 123456789
```
Бот выдаст сотруднику доступ оператора и пришлёт ему уведомление.

### Шаг 3. Добавьте менеджеров

Так же по Telegram ID. Бот спросит регион (кнопками):
```
/add_manager 987654321
```
После выбора региона бот попросит менеджера **поделиться номером телефона**
(кнопкой в Telegram). Пока менеджер не поделился номером — звонить он не сможет.

---

## Почему добавление по числовому ID, а не по @username

Telegram не позволяет боту узнать ID пользователя по `@username` и не разрешает
боту писать человеку первым, пока тот сам не начал диалог. Поэтому схема всегда:

1. Сотрудник пишет боту `/start`.
2. Бот показывает его ID.
3. Сотрудник сообщает ID вам.
4. Вы добавляете его командой.

`@username` сработает только для тех, кто уже писал боту.

---

## Команды администратора

| Команда | Что делает |
|---|---|
| `/add_region <название>` | создать регион |
| `/regions` | список регионов |
| `/add_operator <tg_id>` | добавить оператора |
| `/add_manager <tg_id>` | добавить менеджера (затем выбор региона) |
| `/users` | список всех пользователей с ролями |
| `/remove_user <tg_id>` | деактивировать пользователя |
| `/amo_fields` | показать поля amoCRM с их ID (для настройки адреса) |
| `/me`, `/help` | о себе / справка |

Команды можно вызывать и без аргумента — бот сам спросит данные пошагово.
Прервать любой диалог — `/cancel`.

---

## Настройка поля адреса amoCRM

Адрес выезда хранится в кастомном поле сделки/контакта, и его ID у каждого
аккаунта свой. Чтобы адрес подтягивался в карточку заявки:

1. Выполните `/amo_fields` — бот выведет список полей с номерами (ID).
2. Найдите поле с адресом, запомните его ID.
3. Передайте ID тому, кто настраивает сервер — он впишет его в `AMO_ADDRESS_FIELD_ID`.

Телефон клиента бот находит автоматически (по стандартному полю «Телефон»).

## Контроль и эксплуатация

- **Заявки никуда не теряются**: статусы хранятся в БД, журнал звонков — в таблице
  `call_log`.
- **Если менеджеру/оператору не пришло уведомление** при добавлении — значит он ещё
  не писал боту. Попросите его отправить `/start`, затем повторите команду.
- **Деактивация сотрудника**: `/remove_user <tg_id>` — он перестанет получать заявки
  и пользоваться ботом, но история сохранится.
- **Безопасность**: номер телефона клиента нигде в Telegram не показывается — ни
  менеджеру, ни в сообщениях. Он используется только в момент звонка.

---

## Типичные ситуации

| Ситуация | Что делать |
|---|---|
| Новый менеджер не получает заявки | Проверьте `/users`: активен ли он и тот ли регион |
| Менеджер не может позвонить | Он не поделился номером — пусть нажмёт `/start` и поделится контактом |
| Заявку «увели» — взял не тот | Заявку получает первый нажавший «Беру». Это by design |
| Нужно сменить регион менеджера | Заново `/add_manager <tg_id>` и выберите новый регион |
| Оператор уволился | `/remove_user <tg_id>` |
