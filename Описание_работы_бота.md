# Telegram-бот «Маскированные звонки» — описание работы



## Как устроена работа (общая картина)

1. **Группы.** Менеджеры распределены по рабочим группам (например «Группа-1», «Казань»,
   «Группа-5»). В каждой группе работает **один** менеджер. Меняется человек —
   администратор назначает в группу нового, прежний открепляется.

2. **Заявка.** Оператор вводит номер сделки из amoCRM, выбирает группу — заявка
   мгновенно уходит менеджеру этой группы в личные сообщения Telegram.

3. **Звонок с разрешения.** Менеджер не может позвонить сразу. Он запрашивает
   разрешение → оператор одобряет → менеджер нажимает «Позвонить» → бот через Mango
   соединяет менеджера с клиентом по номеру 8-800.

4. **Журнал.** Все заявки и звонки сохраняются. Записи разговоров попадают в amoCRM
   штатной интеграцией Mango.

---

## Жизненный цикл заявки (по шагам)

```
Оператор создал заявку
        │
        ▼
  [Отправлена менеджеру]  ── менеджер нажимает «Запросить звонок»
        │
        ▼
  [Звонок запрошен]  ── оператор: «Одобрить» / «Отклонить»
        │
        ├── Отклонён → снова «Отправлена» (можно запросить заново)
        │
        ▼ (одобрен)
  [Звонок одобрен]  ── менеджер нажимает «Позвонить клиенту»
        │
        ▼
  [Звонок идёт]  ── Mango звонит менеджеру и соединяет с клиентом
        │
        ▼
  [Заявка закрыта]  ── оператор или менеджер нажимает «Закрыть заявку»
```

## Роль 1. Администратор

Настраивает систему и управляет составом сотрудников. Что делает:

1. **Первый вход.** Пишет боту `/start` — система сразу узнаёт его как администратора
   (его Telegram ID заранее прописан в настройках).
2. **Группы.** Смотрит список — `/groups`. При необходимости создаёт новую —
   `/add_group <название> <город>` (например: `/add_group Группа-4 Москва`).
3. **Добавляет операторов.** `/add_operator` — по числовому Telegram ID сотрудника
   (сотрудник заранее пишет боту `/start` и сообщает свой ID).
4. **Добавляет менеджеров.** `/add_manager` → проще всего **переслать боту сообщение**
   от менеджера (бот сам узнает его ID) → выбрать **группу**. Если группа занята —
   бот спросит подтверждение замены; прежний менеджер открепится, новому бот
   предложит поделиться номером телефона.
5. **Смотрит и убирает людей.** `/users` — список всех с ролями и группами;
   `/remove_user <ID>` — отключить сотрудника (если был менеджером — группа
   освобождается).
6. **amoCRM.** `/amo_fields` — узнать ID поля адреса для настройки;
   `/set_amo_code <код>` — обновить авторизацию amoCRM, если она слетела.

> Важная особенность Telegram: бот не может первым написать человеку и не знает его
> по `@username`, пока тот сам не обратился к боту. Поэтому сотрудника добавляют по
> числовому ID или пересылкой его сообщения.

**Команды администратора:**
`/add_group`, `/groups`, `/add_operator`, `/add_manager`, `/users`,
`/remove_user`, `/amo_fields`, `/set_amo_code`, `/me`, `/help`.

## Роль 2. Оператор отдела продаж

Создаёт заявки и разрешает звонки. Что делает:

1. **Создаёт заявку.** Команда `/order` → вводит номер сделки из amoCRM.
2. Бот показывает данные клиента (имя, адрес). **Телефон скрыт**, но бот
   подтверждает, что номер найден.
3. **Выбирает группу.** Рядом с каждой группой видно имя её менеджера (или
   «свободна»). Заявка уйдёт менеджеру выбранной группы.
4. **Добавляет комментарий** (или нажимает «Без комментария»). Заявка отправлена.
5. **Разрешает звонок.** Когда менеджер запросит звонок, оператору приходит
   сообщение с кнопками **«Одобрить»** / **«Отклонить»**.
6. **Следит за работой.** `/my_orders` — список своих активных заявок.

**Команды оператора:** `/order`, `/my_orders`, `/me`, `/help`.

---

## Роль 3. Выездной менеджер

Выезжает к клиенту и звонит ему. Что делает:

1. **Регистрируется.** После добавления администратором нажимает `/start` и делится
   номером телефона (кнопка «Поделиться номером»). Номер нужен, чтобы система могла
   соединять его с клиентом. **Клиенту этот номер не показывается.**
2. **Получает заявку.** В личные сообщения приходит карточка: имя клиента, адрес,
   комментарий. Телефона клиента в ней нет.
3. **Запрашивает звонок.** Нажимает **«Запросить звонок клиенту»** и ждёт одобрения
   оператора.
4. **Звонит.** После одобрения появляется кнопка **«Позвонить клиенту»**. Нажимает —
   система перезванивает ему на телефон и соединяет с клиентом через номер 8-800.
5. **Повторный звонок.** Нужен ещё раз — снова «Запросить звонок» и дождаться
   одобрения.
6. **Закрывает заявку.** По завершении нажимает **«Закрыть заявку»**.
7. **Свои задачи.** `/my_tasks` — список активных заявок.

**Команды менеджера:** `/my_tasks`, `/me`, `/help`.

---

## Что защищено (гарантии безопасности)

- Номер телефона клиента **никогда** не показывается в Telegram — ни в карточке,
  ни в кнопках, ни в служебных записях. Он используется только в момент звонка.
- Звонить можно только с разрешения оператора. Кнопка «Позвонить» — одноразовая:
  для нового звонка нужно повторное одобрение.
- У каждого сотрудника свои права: менеджер не может одобрять звонки, оператор не
  может звонить за менеджера.
- Все звонки фиксируются в журнале.
