# Telegram-бот «Маскированные звонки» — описание работы

## Как устроена работа (общая картина)

1. **Группы.** Администраторы распределены по рабочим группам (например «Группа-1», «Казань»,
   «Группа-5»). В одной группе может работать **несколько** администраторов. Директор
   добавляет новых в группу и при необходимости отключает прежних.

2. **Заявка.** Менеджер вводит номер сделки из amoCRM, выбирает группу и конкретного
   администратора этой группы (если он там один — шаг пропускается) — заявка мгновенно
   уходит выбранному администратору в личные сообщения Telegram.

3. **Звонок с разрешения.** Администратор не может позвонить сразу. Он запрашивает
   разрешение → менеджер одобряет → администратор нажимает «Позвонить» → бот через Mango
   соединяет администратора с клиентом по номеру 8-800.

4. **Журнал.** Все заявки и звонки сохраняются. Записи разговоров попадают в amoCRM
   штатной интеграцией Mango.

---

## Жизненный цикл заявки (по шагам)

```text
Менеджер создал заявку
        │
        ▼
  [Отправлена администратору]  ── администратор нажимает «Запросить звонок»
        │
        ▼
  [Звонок запрошен]  ── менеджер: «Одобрить» / «Отклонить»
        │
        ├── Отклонён → снова «Отправлена» (можно запросить заново)
        │
        ▼ (одобрен)
  [Звонок одобрен]  ── администратор нажимает «Позвонить клиенту»
        │
        ▼
  [Звонок идёт]  ── Mango звонит администратору и соединяет с клиентом
        │
        ▼
  [Заявка закрыта]  ── менеджер или администратор нажимает «Закрыть заявку»
```

## Роль 1. Директор

Настраивает систему и управляет составом сотрудников. Что делает:

1. **Первый вход.** Пишет боту `/start` — система сразу узнаёт его как директора
   (его Telegram ID заранее прописан в настройках).

2. **Группы.** Смотрит список — `/groups`. При необходимости:
   - создаёт — `/add_group <название> <город>` (например: `/add_group Группа-4 Москва`);
   - редактирует название или город — `/edit_group` → выбрать группу → выбрать поле → ввести новое значение;
   - удаляет — `/delete_group` → выбрать группу → бот покажет предупреждение (сколько заявок,
     кто из людей привязан) → подтвердить. Все пользователи группы открепляются, удаляются
     только незакрытые заявки каскадом.

3. **Приём новых сотрудников (автоматически).** Когда незнакомый человек пишет боту `/start`,
   бот показывает ему его Telegram ID и **одновременно отправляет всем директорам карточку**
   с кнопками «Назначить менеджером» / «Назначить администратором» / «Пропустить». Нажать можно прямо
   в этом уведомлении — вводить ID вручную не нужно. Карточка исчезает из очереди, как только роль
   присвоена.

4. **Очередь необработанных обращений.** `/pending` — показывает список тех, кто уже писал `/start`,
   но роль ещё не получил. Оттуда же можно назначить роль.

5. **Добавляет сотрудников вручную.** Если нужно:
   - `/add_manager` — добавить менеджера по числовому Telegram ID (к группе менеджер не привязан);
   - `/add_admin` → переслать боту сообщение от администратора (бот сам узнает его ID) → выбрать группу.
     В группе может быть несколько администраторов — новый просто добавляется к ним, бот предложит ему
     поделиться номером телефона.

6. **Смотрит и убирает людей.** `/users` — список всех с ролями и группами;
   `/remove_user <ID>` — отключить сотрудника (если был администратором — открепляется от группы,
   остальные администраторы группы продолжают работать).

7. **amoCRM.** `/amo_fields` — узнать ID поля адреса для настройки;
   `/set_amo_code <код>` — обновить авторизацию amoCRM, если она слетела.

> Важная особенность Telegram: бот не может первым написать человеку и не знает его
> по `@username`, пока тот сам не обратился к боту. Именно поэтому новый сотрудник
> сначала пишет `/start`, а директор получает уведомление и назначает роль нажатием кнопки.

**Команды директора:**
`/add_group`, `/edit_group`, `/delete_group`, `/groups`, `/add_manager`, `/add_admin`,
`/pending`, `/users`, `/remove_user`, `/amo_fields`, `/set_amo_code`, `/me`, `/help`.

## Роль 2. Менеджер отдела продаж

Создаёт заявки и разрешает звонки. Что делает:

1. **Создаёт заявку.** Команда `/order` → вводит номер сделки из amoCRM.
2. Бот показывает данные клиента (имя, адрес). **Телефон скрыт**, но бот
   подтверждает, что номер найден.
3. **Выбирает группу.** Рядом с каждой группой видно число её администраторов (или
   «нет админов»).
4. **Выбирает администратора.** Если в группе их несколько — бот предлагает выбрать,
   кому уйдёт заявка; если администратор один — этот шаг пропускается.
5. **Добавляет комментарий** (или нажимает «Без комментария»). Заявка отправлена.
6. **Разрешает звонок.** Когда администратор запросит звонок, менеджеру приходит
   сообщение с кнопками **«Одобрить»** / **«Отклонить»**.
7. **Следит за работой.** `/my_orders` — список своих активных заявок.

**Команды менеджера:** `/order`, `/my_orders`, `/me`, `/help`.

## Роль 3. Выездной администратор

Выезжает к клиенту и звонит ему. Что делает:

1. **Регистрируется.** После добавления директором нажимает `/start` и делится
   номером телефона (кнопка «Поделиться номером»). Номер нужен, чтобы система могла
   соединять его с клиентом. **Клиенту этот номер не показывается.**
2. **Получает заявку.** В личные сообщения приходит карточка: имя клиента, адрес,
   комментарий. Телефона клиента в ней нет.
3. **Запрашивает звонок.** Нажимает **«Запросить звонок клиенту»** и ждёт одобрения
   менеджера.
4. **Звонит.** После одобрения появляется кнопка **«Позвонить клиенту»**. Нажимает —
   система перезванивает ему на телефон и соединяет с клиентом через номер 8-800.
5. **Повторный звонок.** Нужен ещё раз — снова «Запросить звонок» и дождаться
   одобрения.
6. **Закрывает заявку.** По завершении нажимает **«Закрыть заявку»**.
7. **Свои задачи.** `/my_tasks` — список активных заявок.

**Команды администратора:** `/my_tasks`, `/me`, `/help`.

## Что защищено (гарантии безопасности)

- Номер телефона клиента **никогда** не показывается в Telegram — ни в карточке,
  ни в кнопках, ни в служебных записях. Он используется только в момент звонка.
- Звонить можно только с разрешения менеджера. Кнопка «Позвонить» — одноразовая:
  для нового звонка нужно повторное одобрение.
- У каждого сотрудника свои права: администратор не может одобрять звонки, менеджер не
  может звонить за администратора.
- Все звонки фиксируются в журнале.
